ORDEM DE CORTE - INSTALADOR LOCAL

INSTALAÇÃO DE UM CLIQUE:
1. Execute "Ordem-de-Corte-Instalador.exe".
2. Autorize a instalação quando o Windows pedir permissão.
3. O sistema será instalado, iniciado e terá seus atalhos criados automaticamente.

O instalador remove a versão anterior e os dados antigos antes da instalação.
Use-o somente quando quiser iniciar uma instalação totalmente zerada.

Alternativa técnica:
1. Execute "Instalar Ordem de Corte.cmd".
2. Autorize a instalação quando o Windows pedir permissão.

O sistema é instalado em:
C:\Program Files\Ordem de Corte

Os dados ficam em:
C:\ProgramData\Ordem de Corte\dados

O instalador já inclui o Node.js portátil e as dependências necessárias.
Não é necessário instalar Node.js, npm ou internet no computador do cliente.

Para demonstração:
- Abra pelo atalho da Área de Trabalho.
- O navegador abrirá em http://127.0.0.1:4180.
- O ícone do atalho usa a tesourinha do projeto.

Para desinstalar:
Use o atalho "Desinstalar Ordem de Corte" no Menu Iniciar.
Os dados são preservados por segurança.
